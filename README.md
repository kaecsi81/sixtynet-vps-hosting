## SixtyNet 的四组方案里，只有两组能直接对外提供网站服务

**LAX 系列**（LAX-STARTER / MICRO / MEDIUM / LARGE）标了 DDoS Protection，端口正常开放，是标准的建站机型。

**Residential 系列**（Residential-STARTER / MICRO / MEDIUM / LARGE）卖点是住宅 IP，但每张配置卡下面都附了一句：Due to IP risk control reasons, residential IP products do not open ports 80&443。

**Storage 系列**是 RAID 10 大硬盘机型，官网可见的 LAX-Storage-500G 是 4 核 4G、300G 加 200G 赠送、12500 IOPS、10G 网络、10TB 流量，同样带 DDoS 防护。做大图库、做备份站、跑多站点文件存储可以考虑。

先说结论：**要对外提供网站访问，就在 LAX 和 Storage 里选；Residential 和 Residential-Pro 是给需要住宅 IP 出口的其他用途准备的，不是网站服务器。**

## 住宅 IP 听着更像“外贸专用”，为什么反而建不了站

搜索外贸建站时，住宅 IP 经常被说成必需品。它的真实价值在别处：Stripe、Facebook 广告账户、平台店铺环境这类系统会看 IP 属性，住宅 IP 被判定为异常的概率低一些。做独立站本身，Google 从来没把 IP 类型列为排名因素，排名看内容质量和页面性能。

但 SixtyNet 为了控制 IP 风险，直接把住宅 IP 产品的 80、443 端口关了。这等于把网页服务这条路封掉。Residential-Pro 更进一步，默认拒绝外部探测和扫描，只有加白名单或做端口转发的设备才能访问。

## 多少钱的配置够用：按站点规模对号入座

配置表里 CPU 从 2 核到 16 核，很容易让人以为核心数越多越好。跑 WordPress 这类站，真正的瓶颈是内存和磁盘 IO，CPU 很少跑满。

日均一千到两千 PV、做过缓存优化的 WordPress 展示站或询盘站，**2 核 2G 是够的**。装 WooCommerce 之后情况变了：商品列表、购物车、结算流程都要查库，插件数量也上去了，内存吃到 1.5G 以上很常见，2G 会开始吃紧。有订单的站直接上 4G，也就是 LAX-MICRO。

多语言站、多站点矩阵、还要跑 API 接口的，8G 起步，对应 LAX-MEDIUM。LAX-LARGE 比 MEDIUM 贵一倍，多出来的是 8G 内存和 20TB 流量，核心数没变。除非你确实被 8G 内存卡住过，否则这一档的钱花得不值。

磁盘这块 SixtyNet 给的是 NVMe，入门档标 12500 IOPS，中高配 25000 IOPS。这个数字对 WordPress 的数据库读写绰绰有余。反过来说，如果有人拿机械硬盘的便宜机型跟你比价格，那个价差是用页面加载速度换来的，商品图和缓存一多就会显形。

流量基本不用担心。按日均 2000 PV、每页连图片算 1.5MB，一个月约 90GB；就算缓存命中率低、实际翻倍到 180GB，5TB 的额度也只用了不到 4%。你更可能因为内存不够而升级，不会因为流量不够。

## 下单前要盯住的五个细节

**端口。** 住宅 IP 系列关 80/443，Residential-Pro 默认拒绝外部访问。这两条写在配置卡下方，很容易滑过去。

**退款口径。** Residential-Pro 明确写了退款只退到网站余额。其他系列的退款条款官网页面没有统一说明，付款前发个工单问清楚窗口期，比事后争辩有用。

**流量额度的计算周期。** 页面标的是 5TB、10TB 这样的数字，没写清是月流量还是周期总量。这个必须问，差一个字差很多。

**带宽的含义。** 2G / 4G / 10G Premium Network 是端口速率，不代表任何时候都能跑满。共享型带宽在高峰期的实际表现，只能开通后自己测。

**系统选择。** 第三方测评页面把这些洛杉矶机型标注为可安装 Windows。真要装 Windows Server，内存从 4G 起，2G 跑 Windows 会很紧张，这不是 SixtyNet 的问题，是 Windows 本身的占用。

## 常见问题

**外贸站一定要住宅 IP 吗？**
不是。Google 排名看内容和页面性能，不看 IP 类型。住宅 IP 影响的是支付、广告平台的风控判断。为了这个需求单独配一台最小档住宅 IP 做环境，网站跑在 LAX 上，是更省钱的做法。

**2G 内存到底够不够？**
纯展示站、询盘站、做过缓存的 WordPress，够。装了 WooCommerce、多语言插件、十几个扩展的，不够，直接 4G。

**国内登录后台会卡吗？**
洛杉矶到国内的延迟不可能低到香港的水平。官网在部分方案上标了 AS9929 优化，LAX 系列标的是 Premium Network。上传产品图这种操作，实际体验取决于你所在运营商到美西的路由，开通后测一次再决定要不要换线路。

**能不能退款？**
Residential-Pro 只退网站余额，其他系列的条款官网没有统一页面说明，付款前问工单确认窗口期。

**5TB 流量会用完吗？**
中小外贸站用不到 5%。真用完了，说明你的站流量结构有问题（比如被刷、图片没压缩），先查这个再谈升级。
